06

Export

DON'T SKIP THIS

Final formatting checklist

📄 Interior

  • Correct page size
  • Consistent font
  • Consistent chapter headings
  • Correct paragraph spacing
  • Correct page numbers
  • No accidental blank pages

🔍 Proofread

  • Spelling
  • Grammar
  • Punctuation
  • Chapter order
  • Missing pages
  • Broken images
Important: A template is not automatically compatible with every publishing platform. Before publishing, compare the template's size and formatting with the current requirements of your chosen publisher.
